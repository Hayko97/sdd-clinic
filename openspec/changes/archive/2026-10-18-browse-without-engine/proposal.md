## Why
Existing project documents are hidden behind provider sign-in, preventing users from browsing their own setup.
## What Changes
Allow existing projects, specs, agents and skills to be browsed without an authenticated engine; select the first registered project when no valid selection exists.
## Capabilities
### New Capabilities
### Modified Capabilities
- `clinic-interface`: browse registered projects independently of provider authentication.
## Impact
Browser navigation only; provider operations retain backend connection checks.
