## Connection diagnosis and design
`docker compose exec -T clinic codex login status` reports Not logged in. Codex 0.163.0 is installed and compatible. Host sign-in is a different environment from /home/node in Docker. The generated schema from that exact binary supports account/login/start with chatgptDeviceCode and account/login/completed notifications.
Implement optional login behind EngineAdapter. Codex app-server owns sign-in, token storage and refresh; Clinic holds only an ephemeral login ID, verification URL, one-time code, state and bounded error. The service allows one login attempt per engine, supports cancel/expiry/shutdown, and re-probes the same executable before marking connected. Never store device codes or raw login responses in SQLite, run events or project files. Auth endpoints use existing browser session/origin checks. Terminal guidance explicitly uses docker compose exec when containerized.
Endpoints: POST /api/engines/:kind/login {path}; GET /api/engines/:kind/login; POST /api/engines/:kind/login/cancel. A new attempt supersedes a finished one; duplicate active starts are rejected. Changing connection path while signing in is rejected. Login creates no model inference call.
## Chat design
A project-local Developer chat renders stored workflow prompts and outcomes chronologically, with the composer below a scrollable transcript. Reuse run SSE and approvals; planning stages display summaries/status instead of raw proposal JSON. Keep the active agent/engine/model visible. Enter sends, Shift+Enter inserts a newline, Escape stops active work, and Up recalls an earlier prompt only from an empty composer. Local slash shortcuts offer help/connections/specs/agents without changing the root URL.
Store drafts by project and agent in browser session storage. Workflow history stays in SQLite. A subsequent prompt may name a previous workflow in the same project/agent; pass its bounded summary and selected change as context, never another project's records. An unfinished spec review remains an explicit gate. Clarification answers continue the pending workflow; new implementation intent still runs analyze/create-or-refine/approve/implement/QA.
