## Why
Each connected project needs reusable spec creation and implementation skills, visible implementation evidence, and a reproducible Docker runtime.
## What Changes
Install project-local default skills during reviewed setup, expose them in the GUI and inject them into relevant runs. Require duplicate analysis during spec creation and distinguish implemented, pending and unverified behavior. Make Docker Compose the default runtime.
## Capabilities
### New Capabilities
- `project-skills`: project-local skills and evidence-aware spec flow.
### Modified Capabilities
## Impact
Project onboarding, prompt context, project UI and runtime packaging.
