# Complete project and feature documentation

## Why
The workspace hides a capability's archived planning documents, leaving only its accepted spec visible. Setup lacks portable project-level guidance and new changes start with only a proposal. The user requested researched SDD practices, complete feature folders and reusable defaults for every project.

## What Changes
- Install reviewable mission, technology, roadmap and workflow documents plus a native OpenSpec schema with research, proposal, specs, design, validation and tasks templates.
- Scaffold complete change folders, distinguish drafts from approval-ready artifacts, and include project guidance in revision/context tracking.
- Upgrade unchanged default skills while preserving customized skills and existing OpenSpec configuration.
- Show project guidance and linked active/archived feature documents in the project workspace.
- Document Clinic's own capability designs and validation references without inventing new verification results.

## Capabilities
### New Capabilities
None.
### Modified Capabilities
- `spec-workspace`: project guidance, complete change artifacts and readiness checks.
- `project-skills`: portable research-informed default workflow and safe upgrades.
- `clinic-interface`: complete capability document navigation.

## Impact
Project setup, spec repository, authoring prompts, shared file types, workspace UI, default skills, tests and documentation. Preserve native OpenSpec delta/archive behavior and existing custom workflows. No provider protocol or credential changes.
