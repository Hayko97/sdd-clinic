# Public SDD Clinic distribution

## Why
The owner requests an open-source GitHub repository, a container repository and package-manager installation covering CLI and GUI.

## What Changes
- Publish reviewed project source under the owner's selected open-source license.
- Distribute a global npm launcher with all GUI/runtime assets and a version-matched public container image.
- Add reproducible checks, package inspection and release workflows; report publishing/authentication failures explicitly.

## Capabilities
### New Capabilities
None.
### Modified Capabilities
- local-runtime: public installation and release artifacts.

## Impact
Package metadata, public documentation, license, distribution scripts and GitHub Actions. The owner's explicit request authorizes creating the public repository, committing/pushing reviewed project files and publishing releases. It does not authorize publishing credentials, user data or unrelated projects. License and registry preferences are pending; no public source upload until license is resolved.
